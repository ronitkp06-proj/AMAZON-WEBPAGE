# 🛒 Amazon Clone

A simple, Amazon-inspired e-commerce homepage built with **HTML and CSS**. This frontend project recreates the look of an online shopping website with a navigation bar, search interface, promotional banner, product-category cards, and a detailed footer.

## ✨ Features

- Display an Amazon-inspired navigation bar with a logo, delivery location, account labels, and cart icon.
- Show a styled search field with a category selector and search icon.
- Highlight shopping sections such as gaming, student items, electronics, fashion, laptops, watches, merchandise, and toys.
- Display a promotional hero banner and a message about Amazon India.
- Add hover borders to selected navigation elements.
- Include a multi-column footer with informational sections and branding.
- Use local images to style the banner, category cards, and logos.

## 🛠️ Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling, layout, hover effects, and background images
- **[Font Awesome](https://fontawesome.com/)** — navigation and interface icons

## 🚀 Getting Started

No build tools, package installation, or API keys are required.

1. Download or clone this repository.
2. Make sure `index.html`, `style.css`, and all the image files listed below are in the same folder.
3. Open `index.html` in your browser.
4. Explore the homepage layout, shopping categories, and footer.

An internet connection is required to load Font Awesome icons from the external CDN.

## 🔎 How It Works

1. `index.html` defines the navigation bar, search interface, promotional banner, eight shopping-category cards, and footer.
2. `style.css` controls the colors, spacing, layout, background images, and hover effects.
3. Local image files provide the logo, promotional banner, and shopping-category visuals.
4. Font Awesome supplies icons for the location, search, menu, and cart.
5. The page runs directly in a browser without a JavaScript application or backend.
